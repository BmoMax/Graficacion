# Sistema Caído

Prototipo 2.5D de acción desarrollado con Godot 4.

## Abrir el proyecto

1. Instala Godot 4.7 o una versión posterior.
2. En el gestor de proyectos, usa **Importar** y selecciona `project.godot`.
3. Espera a que Godot importe los modelos y las texturas.
4. Ejecuta `main.tscn` con `F6` o el proyecto completo con `F5`.

Las instrucciones de controles, versiones del prototipo y detalles de los personajes están en [LEEME.txt](LEEME.txt).

El repositorio contiene el código fuente, escenas, modelos y texturas necesarios para explorar el prototipo.
